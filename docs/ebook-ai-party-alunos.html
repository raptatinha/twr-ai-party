01
🧭

The 4Ds + Contexto

Fundacao15 + 15 min
The 4Ds
  • Delegation: delegue para IA o que e repetitivo e estruturado
  • Description: descreva contexto, saida esperada e restricoes
  • Discernment: valide qualidade, relevancia e risco
  • Diligence: assuma responsabilidade e transparência no uso
Context management
  • Conversa longa sem higiene reduz qualidade da IA
  • Use /compact para preservar contexto essencial
  • Use /clear para iniciar tarefa totalmente nova
  • Trate tokens como limite de foco e memoria de trabalho
Para lembrar

Boas respostas nao comecam no prompt final. Elas comecam no gerenciamento de contexto ao longo da sessao.

02
🔌

MCP + Playwright MCP

Integracao10 + 25 min
MCP em uma frase
  • Padrao que conecta IA a ferramentas e dados externos
  • Permite acao real, nao so texto gerado
  • Cria fluxo auditavel entre pedido e execucao
Playwright MCP na pratica
  • Use snapshot antes de interagir com a pagina
  • Faca uma acao por vez e valide resultado
  • Evite repeticao cega da mesma tentativa
  • Registre evidencias (estado inicial, acao, estado final)
Fluxo recomendado:
1) Definir objetivo claro
2) Capturar snapshot
3) Escolher elemento correto
4) Interagir (click/fill)
5) Validar estado final
6) Documentar resultado
03
🧪

Playwright CLI + Agents

Hands-on25 + 15 min
Playwright CLI
  • Comandos de execucao local e debug rapido
  • Rodar por suite, arquivo e caso especifico
  • Abrir report e trace para causa raiz
  • Repetir ciclo: falha -> diagnostico -> ajuste -> reexecucao
Playwright Agents
  • Defina objetivo e criterio de sucesso
  • Use para fluxos repetitivos e investigacoes guiadas
  • Evite tarefas vagas sem criterio de parada
  • Sempre mantenha revisao humana no fechamento
# Exemplo de fluxo CLI
npx playwright test
npx playwright test tests/login.spec.ts
npx playwright test -g "checkout feliz"
npx playwright show-report
npx playwright show-trace trace.zip
Para praticar em casa
  • Escolha 1 fluxo da sua aplicacao e rode ciclo completo com CLI
  • Force 1 falha controlada e use trace para diagnosticar
  • Escreva um objetivo agentico com criterio de sucesso em 3 linhas
04
⚡

Cursor + Claude Code + Panorama

Produtividade25 + 10 + 15 min
Cursor (Rules + Skills)
  • Rules para consistencia e seguranca de output
  • Skills para tarefas recorrentes de time
  • Padronizacao reduz retrabalho em PR review
  • Comece pequeno e evolua por evidencias
Claude Code + outras ferramentas
  • Claude Code para leitura/refatoracao orientada a objetivo
  • Codex/Copilot para apoio de codificacao
  • GitHub e Jira no fluxo de colaboracao
  • Grafana para contexto de observabilidade
  • VSCode como ambiente base para muitas equipes
Regra de ouro

Ferramenta boa e a que resolve seu problema com qualidade e governanca. Evite comparacoes por hype.
