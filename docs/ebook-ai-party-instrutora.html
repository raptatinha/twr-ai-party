Dica de conducao

Em publico misto, sempre explique primeiro o "por que", depois o "como". Isso mantem quem e menos tecnico engajado sem perder profundidade para quem e mais avancado.

00-02
🧠

Abertura + Contexto + MCP

40 minutosFundacao
Roteiro sugerido
  • Min 0-5: enquadramento e objetivos da aula
  • Min 5-15: The 4Ds com exemplos de tarefas reais
  • Min 15-30: contexto, tokens, /compact e /clear
  • Min 30-40: MCP como ponte IA <-> ferramentas
Perguntas de engajamento
  • "Qual etapa do seu fluxo mais consome tempo hoje?"
  • "Quando a IA mais te ajuda: gerar, revisar ou investigar?"
  • "Qual foi seu ultimo problema de contexto em conversa longa?"
Risco comum

Comecar direto em ferramenta sem base conceitual. Isso gera uso superficial e confusao em blocos deep.

03-05
🧪

Playwright Deep Blocks

65 minutosDemo pesada
03 · Playwright MCP (25 min)
  • Mostre fluxo: objetivo -> snapshot -> acao -> validacao
  • Evite automacao "cego". Sempre validar estado apos cada acao
  • Se der erro de seletor/ref, use como exemplo didatico de depuracao
04 · Playwright CLI (25 min)
  • Estruture como historia operacional: executar, falhar, entender, corrigir
  • Priorize comandos que o publico realmente vai usar no dia seguinte
  • Se sobrar tempo, compare fluxo local vs CI em alto nivel
05 · Playwright Agents (15 min)
  • Conectar com Delegation dos 4Ds
  • Explicar "criterio de sucesso" como componente obrigatorio
  • Mostrar 1 exemplo de objetivo bem escrito e 1 mal escrito
Script curto de demo CLI:
1) npx playwright test
2) npx playwright test -g "nome do teste"
3) npx playwright show-report
4) npx playwright show-trace trace.zip
5) ajustar e reexecutar
06-08
⚙️

Cursor + Claude + Panorama

50 minutosComparativo pratico
06 · Cursor Deep Dive (25 min)
  • Rules: mostrar beneficio de consistencia de output
  • Skills: mostrar ganho em tarefas recorrentes
  • Fechar com recomendacao de rollout em time pequeno
07 · Claude Code (10 min)
  • Posicione sem comparacao dogmatica
  • Mostre casos bons de uso e limites
  • Conectar com Discernment + Diligence
08 · Panorama (15 min)
  • Codex, VSCode, Copilot, Opus High (visao geral)
  • GitHub + Jira + Grafana como parte do fluxo real
  • Mensagem: stack por objetivo, nao por hype
Se faltar tempo
  • Reduzir bloco 08 para 8 min
  • Levar comparativos detalhados para material async
  • Preservar bloco 06 completo (mais valor pratico)
Transicao para Q&A

Feche com uma frase de consolidacao: "Agora voces tem base para decidir melhor, pedir melhor e validar melhor no uso de IA no trabalho real."

Encerramento

Q&A, Recap e Proximos Passos

09 · Estrutura recomendada (15 min)
  • 10 min: perguntas abertas do publico
  • 3 min: recap dos 5 principais aprendizados
  • 2 min: call to action com exercicio pratico
Recap final (script de 60s)
  • Use The 4Ds para guiar decisoes com IA
  • Gerencie contexto para manter qualidade
  • Use MCP para conectar IA a ferramentas reais
  • Domine fluxo Playwright MCP/CLI/Agents
  • Escale com Cursor Rules/Skills e validacao humana
Pos-aula

Compartilhe os tres arquivos com a turma: slides, ebook do aluno e links de referencia. Sugira um mini-desafio de 30 minutos para consolidar o aprendizado no mesmo dia.
